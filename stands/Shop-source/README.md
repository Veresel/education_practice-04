# Учебная практика ПМ.04 — вариант 19

Приложение обслуживания оборудования: **ремонт измерителей качества воды**.

Исправлены три диагностических метода в `RepairLogic.cs` (вход, возврат, совместный отбор). Готовая операция заявки `OrderService` не изменялась.

## Запуск

Работа выполняется в Windows с .NET SDK 10.0.x. Откройте PowerShell **в папке `stands\Shop-source`**.

Восстановить исходные данные перед независимой проверкой:

```powershell
Copy-Item -LiteralPath baseline.json -Destination work-data.json -Force
dotnet run --project .\Shop.csproj -- .\work-data.json
```

Над каталогом должно быть название области «Ремонт измерителей качества воды», в каталоге пять позиций, пользователь — «Гость».

## Проверочный вход

- Зарегистрированные логины: `client` (Иванов Иван Иванович), `buyer` (Петрова Анна Сергеевна).
- Неизвестный логин `nobody` и пустой логин отклоняются; введённое значение в поле сохраняется.
- После отказа замените логин на `client` и повторите вход — доступ к поиску открывается.

## Поиск, категория и сортировка

1. Войдите как `client`.
2. Запрос `сервисный`, категория `Электроды`: остаются P1 и P5 (P2 той же категории, но без слова; P3 содержит слово, но другая категория).
3. «Все категории» и пустой поиск: по возрастанию P4 (90), P3 (200), P1, P2, P5 (1000); при равенстве стоимости порядок Id возрастает.
4. Дополнительный сценарий варианта: первое слово имени P1 (`Электрод`) даёт P1, P2, P5; полное имя `Электрод pH` оставляет P1 и P5 и исключает P2. Регистр букв результат не меняет.

## Возврат, отмена и заявка

Исполнения в этом варианте — строковые ключи `BNC` и `DIN`.

1. Откройте P1, исполнение `BNC`, количество `1`, добавьте в заявку.
2. «Назад к каталогу» и открытие P5: строка P1 с количеством 1 сохраняется.
3. «Отменить заявку» → «Нет»: строки остаются. «Да»: заявка очищается, остатки не меняются.

## Количество, отказ и подтверждение

1. На чистой копии добавьте 3 единицы P1 / `BNC`. Повторные 3 отклоняются: первая строка, исполнение и поле сохраняются.
2. Замените количество на 2 и продолжите.
3. На отдельной чистой копии подтвердите 2 единицы P1 / `BNC` и 1 единицу P3 / `BNC`. Итог 2200. После записи в `work-data.json`: P1.BNC = 3, P1.DIN = 3, P3.BNC = 1, P3.DIN = 1, в `Orders` один объект с логином `client`.
4. Закройте приложение и запустите той же командой: изменённые остатки сохраняются.

Не подтверждайте заявку поверх уже изменённого файла: сначала восстановите `work-data.json` из `baseline.json`.
